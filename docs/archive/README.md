# Archive

Reference material from earlier versions of PromptForge, kept for study. Nothing here is loaded by the app.

- `extracted/open-design/`: prompts and system prompts extracted from [nexu-io/open-design](https://github.com/nexu-io/open-design) (see its README for attribution).
- `references/system-design-101/`: a link-only index of [ByteByteGoHq/system-design-101](https://github.com/ByteByteGoHq/system-design-101).

The optional Open Design companion service still runs from `docker-compose.yml` using its published Docker image; the empty `open-design` git submodule that used to sit at the repository root was removed.
