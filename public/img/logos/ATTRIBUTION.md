Each logo is a trademark of its respective owner. PromptForge uses them only
to identify the model provider or MCP server a feature refers to; their use
does not imply endorsement by, or affiliation with, those owners.

Files ending in `-light` are the light-colored variants used on the dark theme.

To add a logo: copy `svg/<name>.svg` (and `svg/<name>-light.svg` if it exists)
from that repository into this folder, then reference `<name>` in
`public/js/lib/providers.js` or `mcp/servers.json`.
